# MTHtech katalog – lasersko graviranje

Web katalog: https://matawww.github.io/katalog/

- `index.html`, `app.css`, `app.js` – web stranica (kategorije, pretraga, odabir proizvoda, upit za cijenu)
- `data.js` – podaci o proizvodima (311 proizvoda, 8 kategorija)
- `ispis.html` – A4 verzija kataloga za ispis / PDF
- `ds/` – MTHtech design system (fontovi i tokeni)

Upit: kupac klikom označi proizvode, odabir se pamti u pregledniku. U panelu „Upit” upiše podatke
i pošalje e-mailom (otvara mail aplikaciju, adresa info@mthtech.hr) ili kopira tekst upita i pošalje porukom.

Objava: Settings → Pages → Deploy from a branch → `main` / `(root)`.
Slike proizvoda učitavaju se s weba dobavljača, pa je potrebna internetska veza.
