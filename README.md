# MTHtech katalog – lasersko graviranje

Objava na GitHub Pages:
1. Napravite novi repozitorij (npr. `katalog`) i uploadajte SAV sadržaj ove mape (index.html u korijenu).
2. Settings → Pages → Source: Deploy from a branch → Branch: main / root → Save.
3. Nakon 1–2 minute katalog je na https://<korisnik>.github.io/katalog/

Slike proizvoda učitavaju se s weba dobavljača, pa je potrebna internetska veza.
